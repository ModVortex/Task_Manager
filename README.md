# L1Capstone2
This program is designed to manage tasks assigned to members of a business.
There are two text files user.txt that stores the username and password of a user,
and then there is task.txt that stores info of the task ex. The description of the task.
Firstly the user must login to gain access to the program.
After that there will be a list of options to choose from ex. Viewing the users task.
Some of the tasks are only accessible by the admin for example the "registering a user" option.
